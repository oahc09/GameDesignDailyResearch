## problem
核心受众靠高难度建立身份与声誉（"解谜界的黑魂"是免费营销），但同一难度把大众挡在门外；在原作内降难会撕毁挑战契约。

## context
原作难度已成为品牌资产；存在同一机制的"更平缓表达"空间；续作/衍生版本是可行的分发渠道。

## solution
**原作契约不动，续作重定位**：Snakebird Primer（2019）用 70 关刻意做易触达更广受众——难度身份留在原作，可及性由新产品承载。与同作内开关（Celeste Assist，pattern-000006）互补：前者保护原作体验的纯粹性，后者服务同一产品内的自主选择。

## tradeoffs
- 两个产品拆分用户（老玩家觉得 Primer 太简单，新玩家仍可能先撞上原作）。
- "做易"的续作可能被视为降级（品牌认知风险）。
- 教学改动的"度"难以定义（Primer 仍保留核心机制，只调坡度）。

## known_uses
- game-000030 Snakebird → Snakebird Primer（2019，70 关刻意易化；Wikipedia）

## counterexamples
- game-000008 Celeste：Assist Mode 放在同一产品内且中性命名——两种路线的选择取决于社区对难度身份的敏感度；Celeste 的难度争议（成就贬值讨论）恰好是 Primer 路线要规避的。
