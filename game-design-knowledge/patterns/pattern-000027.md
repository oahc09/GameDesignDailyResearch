## problem
创新机制的最佳来源常是低成本的限时原型，但 jam 作品通常止步于原型。

## context
jam 产出一根"可独立成立的机制"；团队有能力扩展内容与平衡；发行渠道对独立原型开放（Steam EA/众筹/发行商发现）。

## solution
把 jam 原型的核心机制完整化：Nuclear Throne（Mojam 48h → 两年 EA → 2015 正式）、Enter the Gungeon（手工房间系统化——其灵感列表直接引用 NT/Spelunky 等）、Baba Is You（NGJ）、SUPERHOT（7DFPS）、Celeste（PICO-8）、Portal（Narbacular Drop）——知识库内六条独立证据链。

## tradeoffs
- 扩展期漫长（NT 两年 EA；Baba/Portal 的多月至多年）。
- 商标/命名风险（Wasteland Kings → Nuclear Throne 因 inXile 冲突改名）。
- jam 的"乐趣密度"未必可扩展（需保留单机制核心，砍掉其余）。

## known_uses（知识库六链）
- game-000062 Nuclear Throne（Mojam 2013）
- game-000006 Baba Is You（NGJ 2017）
- game-000008 Celeste（PICO-8 三天原型）
- game-000011 SUPERHOT（7DFPS 2013）
- game-000022 Downwell（game-a-week 第 13 作）
- game-000029 Portal（Narbacular Drop → Valve 雇佣）

## counterexamples
- game-000034 Papers, Please：非 jam 起源（9 个月个人储蓄开发）——管道不是必要条件，"一人+可验证核心"同样可行；但 Pope 的灵感（护照检查员重复性）本身就是一种"生活 jam"。
